# Island Desktop

Дата фіксації: **13 листопада 2026 року**. Робоча назва: **Island Desktop**; остаточну назву користувач ще не обрав.

Мета — створити особисту програму з динамічним «острівцем»: спочатку для **Windows**, потім для **Arch Linux**. Взяти за основу ідею та корисні частини наданого мода Windhawk, додати збереження стану й оформлення за відеореференсом.

Поточний етап: **прототип Windows x64 і перший Linux backend для Arch/KDE**, версія 0.3.1. Окремий застосунок на C++20 + Qt Quick/QML, без Windhawk. Є капсула з розкриттям від наведення, пружне виштовхування країв назовні від курсора, годинник, таймер, системний медіаплеєр, гучність Windows, справжня WASAPI-візуалізація, батарея й Bluetooth-пристрої, черга коротких подій, автозапуск і глобальні клавіші, приховування в повноекранних програмах, трей, біла/чорна теми та збереження вибраного розділу. Придатні алгоритми з початкового мода адаптовано з атрибуцією в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Згорнута «Головна» — капсула з очима 148×50 logical із відступом 16 px від краю екрана (типово зверху). На інших вкладках зберігається коротка інформація. Сторону можна змінити: **ПКМ по значку в треї → Налаштування → Край екрана** — зверху, знизу, ліворуч або праворуч; вибір зберігається. Очі залишаються тільки на Головній.

Подвійний лівий клік плавно згортає за 380 мс острівець і плавно робить його напівпрозорим (50%, 450 мс), одразу пропускаючи кліки: кліки проходять до вікон під ним. Тривалість: **Налаштування → Подвійний клік**, типово 5 секунд, діапазон 1–300 секунд. Після завершення острівець повертається згорнутим; для повторного відкриття потрібно відвести курсор і навести знову.

Налаштування відкриваються окремим звичайним вікном через трей. Вони працюють навіть при прихованому острівці, не змінюють вкладку чи закріплення; кнопки налаштувань у панелі більше немає.

## Linux (Arch / KDE Plasma)

Додано Linux-реалізації MPRIS, PipeWire/PulseAudio, BlueZ, батареї з sysfs, XDG-автозапуску й глобальних клавіш KDE. C++ core та QML спільні з Windows.

```bash
./scripts/setup.sh
./scripts/build.sh
./scripts/run.sh --expanded
```

`setup.sh` перевіряє залежності й показує команду встановлення для Arch; сам пакети не встановлює. `build.sh` збирає застосунок, запускає поведінкові тести та QML smoke. Аудіотест створює окремий PipeWire-сервер без фізичних аудіопристроїв; MPRIS тестується на окремому D-Bus.

Типовий запуск використовує X11 або XWayland. На KDE/Wayland очі отримують справжній глобальний курсор через тимчасовий observer KWin, зокрема коли миша над native Wayland-програмою. Він працює тільки під час показу острівця, не змінює налаштування KWin і прибирається при завершенні. API: [KWin Workspace](https://develop.kde.org/docs/plasma/kwin/api/). Без доступного KWin очі стежать усередині вікна; згортання працює через native Enter/Leave незалежно від глобальних координат.

Для native Wayland з layer-shell: `./scripts/run.sh --wayland --expanded`. Перевірка fullscreen у X11 охоплює X11-вікна; fullscreen нативних Wayland-застосунків у режимі XWayland поки не визначається. У native Wayland порядок шарів визначає композитор; повну однаковість із Windows ще не підтверджено. Глобальні клавіші реалізовано для KDE; на інших середовищах вони позначені неактивними.

Плеєр має надавати MPRIS (Spotify, VLC, сумісний браузер). Гучність змінює системний вихід Linux; спектр читає лише monitor цього виходу, без мікрофона чи вигаданих сигналів. Автозапуск вимкнений, доки його не увімкнути в налаштуваннях.

Бінарний файл: `build/IslandDesktop`. Налаштування: `${XDG_CONFIG_HOME:-~/.config}/IslandDesktop/IslandDesktop/settings.ini`; тестові налаштування й знімки: `artifacts/linux/`. Логи звичайного запуску йдуть у термінал; зупинка — Ctrl+C або «Вийти» в треї.

## Запуск Windows

На вкладці «Головна» є необов'язкові очі: стежать за курсором по всьому екрану, засинають після восьми секунд без руху й локального звуку. Перемикач «Очі на головній» — у налаштуваннях; у режимі «Менше руху» вони статичні. На інших вкладках очей немає.

Готова локальна збірка: `dist/IslandDesktop/IslandDesktop.exe`. Для перенесення копіювати весь каталог `IslandDesktop`.

```powershell
.\scripts\run.ps1 -Expanded
```

Наведіть курсор на капсулу на мить або натисніть її, щоб відкрити панель. Після відведення курсора панель згортається із затримкою. Кнопка закріплення утримує її відкритою; стрілка вгорі або Escape згортає та знімає закріплення. ПКМ по значку в треї відкриває меню з окремим вікном налаштувань, приховуванням і виходом.

Музичний розділ отримує трек, виконавця, обкладинку та позицію з медіасесій Windows. Є пауза/продовження, попередній/наступний трек, перемотування й вибір джерела; доступність команд залежить від плеєра. Запустіть музику у сумісному плеєрі, наприклад Spotify. Розділ, тема, зменшення руху, джерело медіа й тривалість таймера зберігаються між запусками; активний відлік після закриття програми не відновлюється.

Вкладок чотири: **«Головна»** (поки лише очі), **«Час»** (годинник і таймер), **«Медіа»** (плеєр і гучність Windows) та **«Пристрої»** (батарея й Bluetooth). Ctrl+1…3 збережені для Часу/Медіа/Пристроїв, Ctrl+4 відкриває Головну. Зміни гучності, підключення пристроїв і зарядки коротко показуються в острівці, після чого повертається вибраний розділ. Вільний край коливається від локального звуку комп'ютера, а контур світиться кольором обкладинки; при відтворенні на iPhone лишається справжній стан плеєра без вигаданої візуалізації.

У налаштуваннях: тема, менше руху, світіння з обкладинки, музичний плеєр, монітор, край екрана, запуск із Windows і глобальні клавіші (типово Ctrl+Alt+Space — показати/сховати, Ctrl+Alt+P — пауза/відтворення).

## Збирання

Потрібні Python і Visual Studio Build Tools із C++ та Windows SDK.

```powershell
.\scripts\setup.ps1
.\scripts\build.ps1 -Package
```

Залежності встановлюються локально в `.tools/`. Збирання включає тести стану та перевірку QML.

## Структура

Один репозиторій для Windows і Linux:

- `src/core/` — спільна логіка без системних викликів: стан, таймер, форма острівця, монітори, адаптовані алгоритми.
- `src/platform/*.h` — спільні інтерфейси контролерів медіа, гучності, звуку й оболонки.
- `src/platform/windows/` — реалізації для Windows (SMTC, Core Audio, WASAPI). Linux-реалізації — у `src/platform/linux/`.
- `qml/` — спільний інтерфейс.

## Головні вимоги користувача

- Спочатку Windows, далі Arch Linux.
- Острівець запам'ятовує вибраний розділ: після згортання знову відкривається на ньому.
- У згорнутому вигляді показує коротку інформацію відповідного розділу.
- Особлива увага до зовнішнього вигляду, ефектів, стилів і анімацій з наданого відео.
- Програма має працювати самостійно, без залежності від установленого Windhawk.
- На цьому етапі лише біла й чорна теми; інші можна додати пізніше.

## Як продовжувати

Зберігати різницю між побажаннями користувача та запропонованими рішеннями. Windows media, гучність і аналіз звуку вже підключено; наступні кандидати — перевірка фізичного аудіовиходу, DPI та різних моніторів. Системні можливості підключати окремими модулями.

Відео — референс оформлення та поведінки. Наявність функції в ролику сама по собі не є вимогою реалізувати її в нашій програмі.

### Головна як панель KDE (Arch)

На «Головній» є меню встановлених застосунків, запущені програми та закріплення (ПКМ → «Закріпити»), час із секундами, повний день і дата та CPU/RAM. Ряд мережі/гучності/Bluetooth/живлення та справжніх значків трея прихований: кругла кнопка зліва внизу плавно розгортає його під годинником. Закріплення й порядок зберігаються; переміщення — через ПКМ → «Ліворуч»/«Праворуч». Іконки програм зменшуються від 32 до 20 logical px, далі ряд прокручується колесом, тачпадом або смугою прокручування.

Лівий клік по активному одиночному вікну згортає його; по згорнутому — відновлює. Група вікон спочатку активує останнє використане, а наступні кліки циклічно перемикають вікна у сталому порядку. Список вікон при лівому кліку не відкривається. Під іконкою — по паличці на кожне вікно (до 4), довша паличка позначає активне. Клік по острівцю може забрати фокус у вікна; програма пам'ятає, яке вікно було активним, тож повторний клік усе одно згортає його.

Перемикання між Головною та іншими вкладками плавне: горбик з очима, відступи, висота й вміст змінюються за 380 мс.

Для вікон нативного KDE Wayland використовуйте `./scripts/run.sh --wayland --expanded`. У режимі X11/XWayland LibTaskManager бачить вікна відповідного X-сервера; нативні Wayland-вікна там не обіцяються. Острівець може повністю замінити нижню панель KDE (автор свою прибрав). Системні плазмоїди панелі (наприклад, історія сповіщень) не тотожні SNI-значкам трея й не перенесені автоматично. Windows-панель буде окремим наступним етапом.

Захоплення спектра з PipeWire/PulseAudio дренує всі готові пакети й чекає на сокеті, а не спить: інакше черга сервера росте ~50 мс щосекунди до ~0,5 с. Діагностика: `ISLAND_AUDIO_TRACE=1 ./scripts/run.sh --wayland` раз на секунду пише кадри/с, затримку джерела й паузи рендеру.

Подвійний клік на кнопках нової панелі не запускає пропускання кліків; жест залишається на вільному тлі/очах. Відкрите меню тимчасово утримує острівець, не змінюючи pin.
