# Island Desktop

Дата фіксації: **11 листопада 2026 року**. Робоча назва: **Island Desktop**; остаточну назву користувач ще не обрав.

Мета — створити особисту програму з динамічним «острівцем»: спочатку для **Windows**, потім для **Arch Linux**. Взяти за основу ідею та корисні частини наданого мода Windhawk, додати збереження стану й оформлення за відеореференсом.

Поточний етап: **прототип Windows x64**, версія 0.3.1. Окремий застосунок на C++20 + Qt Quick/QML, без Windhawk. Є капсула з розкриттям від наведення, пружне виштовхування країв назовні від курсора, годинник, таймер, системний медіаплеєр, гучність Windows, справжня WASAPI-візуалізація, приховування в повноекранних програмах, трей, біла/чорна теми та збереження вибраного розділу. Придатні алгоритми з початкового мода адаптовано з атрибуцією в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Запуск

Готова локальна збірка: `dist/IslandDesktop/IslandDesktop.exe`. Для перенесення копіювати весь каталог `IslandDesktop`.

```powershell
.\scripts\run.ps1 -Expanded
```

Наведіть курсор на капсулу на мить або натисніть її, щоб відкрити панель. Після відведення курсора панель згортається із затримкою. Кнопка закріплення утримує її відкритою; стрілка вгорі або Escape згортає та знімає закріплення. Шестерня відкриває вибір теми. Меню значка в треї дозволяє приховати програму чи вийти.

Музичний розділ отримує трек, виконавця, обкладинку та позицію з медіасесій Windows. Є пауза/продовження, попередній/наступний трек, перемотування й вибір джерела; доступність команд залежить від плеєра. Запустіть музику у сумісному плеєрі, наприклад Spotify. Розділ, тема, зменшення руху, джерело медіа й тривалість таймера зберігаються між запусками; активний відлік після закриття програми не відновлюється.

Вкладка **«Звук»** (Ctrl+4) керує типовим аудіовиходом Windows. Зміни гучності клавішами або іншими програмами коротко показуються в острівці, після чого повертається вибраний розділ. Хвиля реагує на локальний звук комп'ютера; при відтворенні на iPhone залишається справжній стан плеєра. Для гучності та локального спектра потрібен активний аудіовихід Windows.

## Збирання

Потрібні Python і Visual Studio Build Tools із C++ та Windows SDK.

```powershell
.\scripts\setup.ps1
.\scripts\build.ps1 -Package
```

Залежності встановлюються локально в `.tools/`. Збирання включає тести стану та перевірку QML.

## Структура

Один репозиторій для Windows і Linux:

- `src/core/` — спільна логіка без системних викликів: стан, таймер, форма острівця, монітори, адаптовані алгоритми.
- `src/platform/*.h` — спільні інтерфейси контролерів медіа, гучності, звуку й оболонки.
- `src/platform/windows/` — реалізації для Windows (SMTC, Core Audio, WASAPI). Реалізації для Linux з'являться в `src/platform/linux/`.
- `qml/` — спільний інтерфейс.

## Головні вимоги користувача

- Спочатку Windows, далі Arch Linux.
- Острівець запам'ятовує вибраний розділ: після згортання знову відкривається на ньому.
- У згорнутому вигляді показує коротку інформацію відповідного розділу.
- Особлива увага до зовнішнього вигляду, ефектів, стилів і анімацій з наданого відео.
- Програма має працювати самостійно, без залежності від установленого Windhawk.
- На цьому етапі лише біла й чорна теми; інші можна додати пізніше.

## Як продовжувати

Зберігати різницю між побажаннями користувача та запропонованими рішеннями. Windows media, гучність і аналіз звуку вже підключено; наступні кандидати — перевірка фізичного аудіовиходу, DPI та різних моніторів. Системні можливості підключати окремими модулями.

Відео — референс оформлення та поведінки. Наявність функції в ролику сама по собі не є вимогою реалізувати її в нашій програмі.
