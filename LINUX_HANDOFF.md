# Передача на Linux — 13.11.2026

Користувач попросив зберегти всі поточні зміни в `main`; наступний агент працюватиме на Linux. Спочатку прочитай `AGENTS.md` і README. `PROJECT_CONTEXT.md`, `docs/` та локальні артефакти ігноруються git й можуть бути відсутні після клонування.

- Проєкт уже має Linux backend для Arch/KDE: «Головна» замінює панель KDE (користувач свою прибрав), програми/закріплення/трей, CPU/RAM; спільні core/QML. Запуск: `./scripts/setup.sh`, `./scripts/build.sh`, `./scripts/run.sh --expanded`; native KDE Wayland: `./scripts/run.sh --wayland --expanded`.
- Збережено поточні спільні QML-правки: час треку замість компактної play/pause, прибрана стрілка вниз, змінена амплітуда хвилі. Їх не відкочувати як випадкові правки цієї сесії. Зберігати вкладку/pin, анімації 380 мс та окреме вікно налаштувань.
- Windows: guardian приховує справжні панелі Explorer, звільняє зарезервовану смугу на обох моніторах, відновлює власні зміни після виходу/аварії, має lock/unlock gate й обмеження повторів. Це обхідний механізм: він **не гарантує блокування показу до появи**. Користувач відхилив затримане приховування після Win+L як готове виправлення.
- Окремо додано експеримент `src/platform/windows/taskbarprototype/` (власні EXE/DLL, MinHook, точні PDB-символи). Він не підключений до основної програми та не потрібен Linux. Мета — блокувати внутрішні Unhide/ShouldTaskbarBeExpanded в Explorer без Windhawk. Живі Win+L, перезапуск Explorer, відсутність спалаху та повне відновлення ще **не підтверджені**; не видавати прототип за готову функцію і не замінювати ним production до цих перевірок. Див. його README й `scripts/taskbar-prototype.ps1`.
- На Linux спочатку зібрати й перевірити спільні зміни, далі уточнити наступне завдання користувача. Windows DLL/WinAPI не переносити до `src/core/`. Pulse-тести — лише `scripts/test-pulse.sh`, D-Bus — ізольована сесія; не змінювати реальне відтворення чи гучність для тестів. Дрібні візуальні правки не потребують нових тестів.

Перевірки цієї передачі наведено у повідомленні коміту; Linux у Windows-сеансі не запускався. Push надалі — лише на пряме прохання користувача.
