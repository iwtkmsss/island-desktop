# Island Desktop

Перед роботою прочитати `PROJECT_CONTEXT.md`. Вимоги та матеріали: `docs/`, `references/`.
Журнали сесій: `docs/session-log-*.md`; найсвіжіший — `docs/session-log-2026-11-13-claude-panel-sync.md` (Windows перед переносом — `docs/session-log-2026-11-12-part4.md`).
`PROJECT_CONTEXT.md` і `docs/` — локальні файли поза git; якщо їх немає після клонування, працювати за цим файлом і README.

- Окремий застосунок C++20 + Qt Quick/QML + CMake. Windhawk не потрібен.
- Спочатку Windows; перенесення на Arch Linux — наступний етап.
- Поки лише біла й чорна теми. Не додавати інші без запиту.
- Не губити вибраний розділ при згортанні та тимчасових подіях.
- Музика підключена до Windows SMTC. Порожній стан має пояснювати, що потрібно запустити сумісний плеєр; не повертати вигадані треки.
- Користувач підтвердив керування Spotify при відтворенні на iPhone. Не вимагати повторно перемикати відтворення на ПК заради керування.
- Гучність — Windows Core Audio, спектр — локальний WASAPI loopback. Без локального сигналу показувати статичний стан SMTC; не повертати вигадану візуалізацію. Не плутати гучність Windows із гучністю iPhone.
- Fullscreen на моніторі острівця тимчасово прибирає форму й native hit region, зберігаючи вкладку, розгорнутість і pin. Ручне приховування не скасовувати. Події гучності не перекривають завершення таймера.
- Придатні алгоритми з наданого мода використовувати повторно з атрибуцією; потоки й налаштування адаптувати до Qt. Деталі: `THIRD_PARTY_NOTICES.md`, `docs/interaction-design.md`.
- Наведення відкриває без захоплення фокуса; вихід курсора закриває із затримкою. Escape не повинен одразу відкривати панель знову. Закріплення утримує панель відкритою.
- Курсор усередині виштовхує контур назовні вздовж зовнішньої нормалі (до 5,5 px), не втягує його. Дні тижня скорочувати як Пн/Вт/Ср/Чт/Пт/Сб/Нд, не через slice повного слова.
- Не додавати тести для дрібних візуальних правок. Зміни логіки таймера та збереження перевіряти поведінковими тестами.
- Windows: збирання й перевірки `./scripts/build.ps1 -Package`, запуск `./scripts/run.ps1 -Expanded`.
- Linux (Arch/KDE): залежності `./scripts/setup.sh`, збирання/тести `./scripts/build.sh`, запуск `./scripts/run.sh --expanded`. Типово X11/XWayland; `--wayland` — layer-shell. На KDE/Wayland глобальний погляд — через тимчасовий observer KWin; без нього — лише всередині. Вихід миші визначати native Leave, не за потенційно застарілим QCursor XWayland. Глобальні клавіші — KDE. Не видавати fullscreen нативних Wayland-вікон у XWayland за перевірений.
- Linux-захоплення Pulse: за прохід дренувати всі готові події й чекати на сокеті, не одна ітерація + sleep (інакше затримка росте до ~0,5 с). Тест подає тон після 8 с тиші.
- Linux-аудіотести запускати лише через `scripts/test-pulse.sh` (окремий сервер без фізичних пристроїв); D-Bus-тести — через dbus-run-session та `scripts/test-dbus.sh`. Не змінювати реальну гучність/відтворення заради тестів.
- `references/original-mod/` — незмінний референс. Новий код писати в `src/` і `qml/`.
- Один репозиторій для Windows і Linux. `src/core/` — спільна логіка без системних викликів; `src/platform/*.h` — спільні інтерфейси контролерів; `src/platform/windows/` — реалізації Windows, майбутні Linux-реалізації — у `src/platform/linux/`. QML спільний.
- `.tools/`, `build/`, `dist/`, `artifacts/` — локальні залежності й результати збирання, не джерельний код.
- Компактна Головна — звичайна капсула 148×50 logical із відступом 16 px від краю; сторона top/bottom/left/right у MonitorController (`display/dockEdge`). Подвійний лівий клік плавно згортає за 380 мс, знімає pin та плавно робить острівець напівпрозорим (50%, 450 мс), негайно очищаючи native input region на ui/passThroughSeconds (типово 5, 1–300 с); після завершення не відкривати автоматично й не скасовувати manual hide/fullscreen. Налаштування — окреме SettingsWindow через ПКМ у треї; не повертати шестерню чи embedded settings у панель і не зв’язувати їхню видимість із expanded острова.
- Відкриття й згортання — 380 мс OutCubic через спільну expansionProgress для width/height/radius; не повертати 900 мс чи розсинхронені анімації. Шар загальної прозорості — на fixed frame, не shell (інакше обрізається контур/тінь). Головна на Linux замінює нижню панель KDE (користувач її видалив; бекап локально в `artifacts/kde-panel-backup/`). Трей-ряд прихований за круглою кнопкою; перехід Головна↔інші вкладки — спільна homeProgress 380 мс.
- Вкладки: «Головна» (`home`; на Linux — програми, трей, годинник, CPU/RAM), «Час» (`time`, годинник/таймер), «Медіа» (`media`), «Пристрої» (`devices`). Очі показувати лише на «Головній»; для них використовувати gazeX/gazeY та pointerActivity, не обмежені координати пружного краю pointerX/pointerY. Нові модулі додавати як вкладку або як подію через чергу `src/core/eventqueue.h`, не в обхід неї.
- Світіння контуру з обкладинки завжди світле; для сірих обкладинок — нейтральний світлий тон. Хвиля від музики випинається лише назовні й залежить від гучності та басів; не повертати знакозмінну синусоїду.
- `implicitHeight` сторінок не повинна залежати від видимості; не ховати `expandedContent` через `visible`. Native frame фіксований — нові налаштування вміщати прокруткою.
- Git: гілка `main`, публічний origin. Коміти — окремими логічними кроками; push і force push лише на пряме прохання користувача. Не міняти автора комітів і не додавати в git `docs/`, `PROJECT_CONTEXT.md`, відео й кадри референсу.
- Субагенти, що працюють паралельно, не збирають проєкт (спільна тека `build/`); збирає й перевіряє оркестратор.
